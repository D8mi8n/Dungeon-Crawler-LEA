Pixelify Sans by Stefie Justprince / Typecalism Foundryline.

Unmodified static Regular and Bold fonts from:
https://github.com/eifetx/Pixelify-Sans/tree/main/fonts/ttf

Licensed under SIL Open Font License 1.1. The complete license is included in
Assets/StreamingAssets/Licenses/PixelifySans-OFL.txt and shipped with the game.

Unity imports both fonts as Dynamic / Hinted Raster. DungeonHUD uses point
filtering for crisp pixel edges, including after dynamic font atlas rebuilds.
